# Audi Nuvolari Scroll Showcase

An unofficial, single-page Audi Nuvolari fan showcase built with HTML, CSS, and JavaScript. It includes a scroll-driven stat sequence, responsive layouts, reduced-motion support, and image assets in `assets/images/`.

## Run locally

Open `index.html` in a modern browser. The page loads fonts from Google Fonts, so those fonts require an internet connection.

## Deploy

Enable GitHub Pages for the `main` branch and repository root (`/`).
